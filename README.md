# Skills

Skills for design refinement and review.

| Skill | Purpose |
| --- | --- |
| [design-refinement](design-refinement/SKILL.md) | Refine an existing interface through capture, review, and correction. |
| [review-pr](review-pr/SKILL.md) | Review a pull request and report findings. |
| [council](council/SKILL.md) | Combine two independent reviews into one verdict. |

Copy a skill directory into the skills directory for your agent. Keep its `references` and `scripts` directories with it.

These are the original Claude skill files. Some steps need T3 Code tools or the named agent models. The design refinement skill also refers to a separate `dataviz` skill, which is not included here. Its optional capture script needs Playwright and a saved browser sign-in state; neither is included.
